# 审稿量表：100 分制

本量表服务于 `SKILL.md` 的 Review Mode。十个维度，每项 10 分，总分 100 分。

## 使用方法

1. 第一遍通读全文，不做修改判断。
2. 第二遍按十个维度逐项评分，每项根据四个档位（0–3 / 4–6 / 7–8 / 9–10）给出分数和证据。
3. 第三遍定位可执行的删 / 留 / 补 / 换。
4. 评价必须引用具体句子或位置。禁止只说"很高级""很有感觉""很克制""很有电影感"。

## 总分解释

| 分数 | 结论 |
| --- | --- |
| 90–100 | 极强：机制成熟，证据与人物互相支撑，可直接精修发布 |
| 80–89 | 成立：整体可读，局部有密度失衡或人物单薄等可修问题 |
| 70–79 | 有明显可修问题：强段落与重复段落并存，模仿痕迹明显 |
| 60–69 | 技巧先于故事：掌握表面元素，深层机制未生效 |
| <60 | 建议重新设计：依赖炫富、金句或猎奇，尚未形成完整叙事 |

## 评分维度

### 1. Opening（10 分）

开头五句内能否建立尺度、关系与悬念。

- 0–3：开头是背景介绍、天气或内心独白，五句内没有建立任何具体尺度与关系。
- 4–6：有具体细节，但尺寸 / 关系 / 悬念只成立一项，其余靠后补。
- 7–8：两个尺度（数字、物件或空间）与人物关系快速并置，形成反差。
- 9–10：开头信息同时建立尺度、关系与未解问题，且与 Unbuyable Gap 直接相关；删掉任何一句都会削弱开头。

### 2. Reader State（10 分）

每条重要信息是否改变读者的 K / J / E / T。

- 0–3：信息不改变任何读者状态，纯描述和氛围句堆叠。
- 4–6：有部分信息改变状态，但大量句子只承担"写得好"的功能。
- 7–8：大多数场景至少有一条信息改变一个状态，K / J / E / T 有所侧重。
- 9–10：场景之间状态连续变化，每一条重要信息都能指出它改变了哪个状态，无功能氛围句为零。

### 3. Unbuyable Gap（10 分）

是否存在一个贯穿全文的资源无法解决的缺口。

- 0–3：没有缺口，人物问题全部可以用钱解决，或问题含糊不清。
- 4–6：存在缺口迹象，但与财富机制无关，或中断于中段。
- 7–8：一个清晰缺口贯穿，且与"系统解决问题"的 Pattern 形成对照。
- 9–10：缺口唯一、贯穿、在 Pattern Break 和结尾回收中两次显形；删除它故事不成立。

### 4. Character / Narrator Gap（10 分）

叙述者的自我叙述与行为事实是否形成可被读者识别的落差。

- 0–3：叙述者解释一切，读者没有独立判断空间。
- 4–6：有落差但叙述者或作者在关键处跳出来解释，打断判断。
- 7–8：三列表（相信 → 事实 → 结论）成立，读者能形成独立判断，作者不纠正叙述者。
- 9–10：落差贯穿全文，读者至少一次"先相信叙述者、后被行为事实推翻"，且复盘合理。

### 5. Numbers（10 分）

数字是否可信、可见，并承担叙事功能。

- 0–3：没有数字，或数字纯炫富、纯装饰、明显随意编造。
- 4–6：数字真实，但只承担"显得真实"，不改变判断、不形成反差。
- 7–8：数字建立尺度或反差，至少两处改变读者对人物的判断。
- 9–10：数字与 Pattern / Break / Return 联动，同一类数字被回收，且经得起常识核查。

### 6. Objects & Evidence（10 分）

核心物件与证据是否至少出现两次且含义改变。

- 0–3：没有贯穿物件，或物件只在结尾临时出现充当象征。
- 4–6：物件出现多次，但每次含义相同，读者无法感知变化。
- 7–8：核心物件至少两次出现，末次使用时关系已经改变。
- 9–10：物件同时服务人物塑造、事件推进与结尾回收，且"用错 / 放回 / 找回"类动作揭示隐藏状态。

### 7. Labor / Power / Absence（10 分）

服务系统劳动是否可见，缺席是否被衬托出来。

- 0–3：没有劳动，或助理、司机、保洁只是背景道具。
- 4–6：有劳动描写，但只展示财富，不与缺席形成对照。
- 7–8：劳动链条可见（请求如何被多人接力完成），"谁没来"被显然衬托。
- 9–10：劳动成本与后果被写出，唯一未完成的事恰好是只能本人完成的事。

### 8. Information Gap（10 分）

读者知道的 > 叙述者承认的，信息是否走间接渠道。

- 0–3：叙述者知道什么就交代什么，读者没有拼图空间。
- 4–6：有信息差但由作者直接补出（跳出来纠正叙述者）。
- 7–8：信息通过账单、提醒、助理汇报、照片等间接渠道进入。
- 9–10：读者在多个节点通过间接证据自行拼出叙述者不愿承认的事，作者从不代述。

### 9. Rhythm & Compression（10 分）

节奏是否有变化，压缩是否到位，技巧是否重复。

- 0–3：节奏单一（持续抒情或持续冷句），明显可以删掉的部分未删。
- 4–6：有节奏意识，但中段存在三个以上同构场景或重复炫技。
- 7–8：短句主导、长句服务流程，删稿到位，三场内无同构套路。
- 9–10：每个场景节奏承担不同功能，压缩后信息密度均匀，无冗余结尾总结。

### 10. Ending & Credibility（10 分）

结尾是否回收开头且不加解释，整体事实是否可信。

- 0–3：结尾总结人生 / 宣布主题 / 用抽象情绪收束；事实存在硬伤。
- 4–6：结尾有回收到物件，但附带解释；或事实细节经不起核查。
- 7–8：结尾回收数字 / 物件 / 动作 / 空间，含义已变，不加解释。
- 9–10：结尾完成双重回收（物件 + 数字或空间），时间线、金额、行业流程、人物处理全部稳妥可查。

## 诊断信号

### 技巧先于故事（对应 60–69）

出现以下任意两项：

- 几乎每段都有可截图传播的句子。
- 同类天价数字连续出现但不改变判断。
- 同一套"劳动执行 + 冷句收尾"连续在三场以上出现。
- 每个场景都以短促冷句结束，节奏无变化。
- 物件、账单、空间出现后不回收。

### Unbuyable Gap 缺失（对应 <60）

- 人物任何需求都能用钱解决，或干脆没有需求。
- 结局靠事件巧合收场，而非人物行为与缺口相遇。
- 作者用旁白解释人物动机，叙述者始终正确。

### 事实脆弱

逐项核对：

- 金额、币种、面额与现金重量的换算。
- 交通工具的航程、时差、机场与流程。
- 医疗、酒店、金融、法律服务的真实操作方式。
- 年份、年龄、节日、日历与时间线自洽。
- 现实人物姓名、家庭信息与可识别账户。

核对不实的细节，先把数字降级为约数，再不行改成转述，最后直接虚构。

## 四类修改建议

### 删

删除：只显示财富的细节、重复表达同一情绪的句子、无功能氛围句、重复炫技、多余结尾总结、作者解释。

### 留

保留：能同时承担人物塑造、关系变化与意象回收的场景；唯一但被 Pattern 支承的打破点。

### 补

补充：Unbuyable Gap 的明确化（让读者知道什么买不到）、另一人物的矛盾行为、间接信息渠道、一个无法委托他人的动作、被省略的最后一句解释的位置。

### 换

- 抽象悲伤 → 物件状态
- 道德判断 → 行为事实
- 泛泛金额 → 能形成画面的数量
- 直接告知 → 账单 / 提醒 / 第三人转述
- 现实人物 → 充分虚构的身份
- 结尾总结 → 回收 + 留白

## 推荐输出结构

Review Mode 按 SKILL.md 规定顺序输出：

1. 一句话结论（含总分）
2. 最强三处（引用具体句子或位置）
3. Reader State（K / J / E / T 是否被信息改变）
4. Unbuyable Gap（是否存在、是否唯一、是否贯穿）
5. Narrator Gap（读者能否形成独立判断）
6. 技巧重复问题（相同套路是否连用超过三场）
7. 事实可信度
8. 删 / 留 / 补 / 换
9. 用户要求时，再给重写稿
